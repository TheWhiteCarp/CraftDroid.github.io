About CraftDroid

CraftDroid is a native Android application designed to provide reliable, low-overhead dedicated server hosting on modern ARM64 mobile hardware.

  • ☕ Java Edition: Powered by official headless OpenJDK runtimes, supporting PaperMC, PurpurMC, FabricMC, and Vanilla servers.
  • 🪨 Bedrock Edition: Powered by official Mojang Bedrock Dedicated Server (BDS) x86_64 binaries executed via Box64 dynamic recompilation.
  • ☕+🪨 Crossplay Edition: Powered by PaperMC with integrated GeyserMC and Floodgate, enabling Bedrock and Java players to join the same world simultaneously.
  • 🌐 Global Tunneling: Built-in Playit.gg Anycast agent integration allowing public multiplayer access without port forwarding.
  • 🛡️ Hardware & Thermal Protection: Real-time CPU and battery temperature monitoring with automatic emergency shutdowns to safeguard mobile device health.
