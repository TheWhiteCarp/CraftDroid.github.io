1. Introduction & Core Privacy Philosophy

CraftDroid ("we", "us", or "our", operated by TheWhiteCarp) is built with an uncompromising local-first, privacy-by-design architecture. CraftDroid enables users to run, configure, and manage Minecraft Java Edition (PaperMC, PurpurMC, FabricMC) and Minecraft Bedrock Dedicated Servers directly on their Android devices utilizing local container runtimes (PRoot and Box64).

We firmly believe that your server worlds, player inventories, private chat logs, and game configurations belong exclusively to you. To ensure absolute transparency, we delineate our application's direct operations and third-party network integrations below:

  • Zero Developer Data Collection (First-Party): We do not operate external application servers, central player databases, analytics trackers, or user profiling systems. We do not collect, monetize, log, or transmit your personal data, email address, IP address, or game world files. No account registration or sign-in is required to use CraftDroid.
  • 100% On-Device Local Server Execution: Minecraft server processes, JVM environments, world saves, player data files, and server properties are executed and stored entirely within your device's private, sandboxed app storage.
  • Third-Party Networking & Advertising: To allow friends over the internet to connect to your local server without complex router configuration, CraftDroid integrates the optional Playit.gg tunneling client. In addition, ad-supported builds integrate Google AdMob to fund ongoing maintenance. Third-party data handling is detailed in Section 4.

2. What Information We Do NOT Collect

Unlike cloud server hosting providers, CraftDroid maintains a strict zero-telemetry policy for the developer. Specifically:

  • No Personal Identifiers: We do not ask for or collect your name, email, phone number, physical address, or account credentials.
  • No World or Gameplay Inspection: Your world seed, map files, inventory data, server console logs, operator lists (ops.json), player whitelists (whitelist.json), and in-game chat messages are never transmitted to or visible to the developer.
  • No Biometric or Device Location Data: CraftDroid does not access or collect GPS location, Bluetooth beacons, camera, microphone, or contacts.
  • No Analytics or Tracking SDKs: CraftDroid contains zero third-party behavioral analytics, crashlytics scrapers, or session recording SDKs.

3. Local Storage, World Custody & Data Retention

All server installations, JVM dependencies, configurations, and world files reside strictly in local storage on your Android device:

  • Sandboxed Rootfs Directory: Server runtime files (OpenJDK, Paper/Purpur JARs, Bedrock server binaries) are stored inside the app-specific internal directory: /data/data/com.example.craftdroid/files/.
  • User Storage Access Framework (SAF): When creating world backups or exporting server archives (.tar.gz / .zip), CraftDroid uses Android's native Storage Access Framework. You retain complete custody over the destination directory (e.g., Downloads, Documents, or external SD card).
  • Complete User Deletion Rights: You can completely erase any server environment, reset credentials, or clear worlds at any time through the in-app Worlds and Settings menus. Clearing application data via Android System Settings or uninstalling CraftDroid permanently deletes all local server instances, world data, and configurations immediately from your device.

4. Third-Party Services & Network Data Transits

To provide multiplayer internet connectivity, fetch official game server binaries, and deliver advertisements, CraftDroid interacts with the following external services:

A. Playit.gg (Encrypted Tunneling Service)

CraftDroid integrates the open-source Playit.gg agent daemon to enable multiplayer internet connections without port forwarding:

  • Network Transit: When a tunnel is activated, incoming Minecraft multiplayer packets (TCP port 25565 for Java, UDP port 19132 for Bedrock) are routed securely through Playit.gg's global edge network to your Android device.
  • Data Processed by Playit: Playit.gg routes connection traffic and processes connecting player IP addresses to establish routing channels and mitigate DDoS attacks. Playit does not inspect the contents of your Minecraft world files.
  • Playit Account Management: Account claiming and tunnel assignment occur directly between your browser and Playit.gg. Your Playit secret tokens are saved exclusively in your local Android device storage.
  • Privacy Policy: For details on Playit.gg's data handling, consult the Playit.gg Privacy Policy.

B. Google AdMob (Advertising Network)

Public releases of CraftDroid on Google Play display advertisements via Google AdMob to support ongoing development and maintenance:

  • Data Processed by AdMob: The Google Mobile Ads SDK may collect device identifiers (such as the Google Advertising ID / GAID), coarse IP-based approximate location (for geographical ad serving and fraud detection), device model, carrier, and ad interaction telemetry.
  • User Choice & Privacy Regulations (GDPR / CCPA): Users in the European Economic Area (EEA) and the UK are presented with a consent modal (via Google UMP) to select personalized ads, non-personalized ads, or revoke consent. All users can reset or delete their Advertising ID at any time via Android System Settings: Settings > Google > Ads > Delete advertising ID.
  • AdMob Governance: Review Google's Advertising Privacy & Terms for additional information.

C. Upstream Server Binary & Engine Repositories

When you install or update a server engine, CraftDroid communicates directly with official upstream repositories via encrypted HTTPS:

  • Java Edition Engines: PaperMC API (api.papermc.io), PurpurMC API (api.purpurmc.org), and FabricMC Meta (meta.fabricmc.net).
  • Bedrock Edition Binaries: Mojang Official Bedrock Dedicated Server CDN (minecraft.net/bedrockdedicatedserver).
  • Crossplay Bridges: GeyserMC & Floodgate API (download.geysermc.org) and ViaVersion repositories.
  • Runtimes: Adoptium / OpenJDK headless Linux binaries.
  • Transit Scope: Only standard HTTP GET requests are executed to download the requested release JARs and ZIP archives. No personal data, telemetry, or device identifiers are shared with these repositories.

5. Android Device Permissions & Technical Justifications

In adherence to the Google Play Developer Policy and the Principle of Least Privilege, CraftDroid requests only the permissions strictly required to host a server environment:

Permission Type Technical Justification
android.permission.INTERNET Normal Required for downloading server software binaries, establishing Playit.gg encrypted tunnels, routing multiplayer game traffic, and displaying AdMob ads.
android.permission.FOREGROUND_SERVICE Normal Required to keep the Minecraft server engine and tunneling daemons alive in the background while players are connected and the app is minimized.
android.permission.FOREGROUND_SERVICE_SPECIAL_USE Special Use Declared for long-running, user-initiated local server execution on Android 14+ (API 34).
android.permission.POST_NOTIFICATIONS Runtime (Android 13+) Required to display the persistent server status notification, server lifecycle events (starting, running, stopping), and thermal emergency alerts.
android.permission.WAKE_LOCK Normal Prevents the device's CPU from entering deep sleep while players are connected to an active server session.
android.permission.REQUEST_IGNORE_BATTERY_OPTIMIZATIONS Special Allows users to exempt CraftDroid from aggressive OEM background task killers, preventing premature server crashes.
android.permission.VIBRATE Normal Provides haptic feedback during critical thermal threshold alerts and server state transitions.

CraftDroid does not request or access sensitive permissions including: Camera, Microphone, GPS Location, Contacts, Call Logs, SMS, or External Broad Storage (MANAGE_EXTERNAL_STORAGE).

7. Hardware Safety, Thermal Protection & Battery Notice

Hosting a dedicated game server on mobile hardware produces sustained CPU computation and heat generation. CraftDroid incorporates protective features, including:

  • Automatic Thermal Shutdown: Monitors device thermal zones and gracefully initiates server shutdown when temperatures exceed safe limits (default: 48°C emergency stop).
  • User Operational Responsibility: Users should operate servers in well-ventilated conditions, avoid thermal-insulating protective cases during long sessions, and use quality chargers to preserve battery health. The developer is not liable for device thermal wear or battery degradation resulting from continuous server operation.
